# Principles of Urban Informatics (NYU CUSP, Fall 2017)

Coursework from the core urban informatics course at NYU's Center for Urban Science + Progress (CUSP). Each folder is one assignment and has its own README.

| Folder | Topic |
|---|---|
| `HW01` | Reproducible workflows: shell setup, Git, environment variables |
| `HW02` | MTA Bus Time API: live bus positions for a route, from the command line |
| `HW03` | Simulation: the Central Limit Theorem and the Law of Large Numbers; Citi Bike ridership by gender |
| `HW04` | Hypothesis testing on Citi Bike trips: day vs. night trip duration, cold vs. hot months |
| `HW05` | Ordinary least squares regression |
| `HW06` | NYC building energy use joined to PLUTO tax-lot data |
| `HW07` | Statistical analysis write-up with peer review |
| `HW08` | Cyclist crashes with motor vehicles: does time of day, week or year matter? (R) |
| `HW09` | Census API and GeoPandas: mapping NYC Public Use Microdata Areas |
| `HW10` | Subway ridership time series by station and fare type |
| `HW11` | Clustering NYC ZIP codes on Census ZIP Code Business Patterns |
| `Midterm` | NYC yellow taxi trips: trip duration and tipping |

## Stack

Python (pandas, NumPy, SciPy, statsmodels, GeoPandas, seaborn) · R · Jupyter
